# Contributing

Thank you for helping improve HappyMe.

## Ways to contribute

- Improve quiz wording or result descriptions
- Fix accessibility or responsive-layout issues
- Add documentation or usage examples
- Report bugs and suggest features

## Development

HappyMe is a dependency-free HTML application. Open `HappyMe_Happiness_Quiz.html` in a browser to test changes.

Before submitting a change:

1. Test the full five-question flow.
2. Test Back, Restart, and Copy Result actions.
3. Test desktop and mobile layouts.
4. Verify keyboard focus and screen-reader-friendly behavior.
5. Avoid adding tracking or server-side data collection.

## Pull requests

Keep pull requests focused and describe:

- The problem or improvement
- What changed
- How it was tested
- Any accessibility impact

For large feature proposals, open an issue before implementation.
