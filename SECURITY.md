# Security Policy

## Reporting a vulnerability

Please do not post security vulnerabilities in public issues.

Report a suspected vulnerability privately through GitHub by opening a security advisory for this repository:

1. Open the repository page.
2. Select **Security**.
3. Select **Advisories**.
4. Choose **Report a vulnerability**.

Include a clear description, affected file or section, reproduction steps, and any relevant proof of concept. Please avoid using real personal data in reports.

## Response expectations

The maintainer will review reports as time permits and may request additional details. Because this is a small static project, fixes may be delivered through a direct patch or a future release after impact is confirmed.
