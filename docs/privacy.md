# Privacy Statement

## Data collection

The HappyMe application does not collect, transmit, store, or sell quiz answers. There are no accounts, analytics, cookies, APIs, database connections, or third-party scripts in the application.

## In-memory state

Selected answers exist only while the page is open. Reloading or closing the page resets the quiz. The application does not write answers to local storage or browser history.

## Copy result feature

When the user selects **Copy my result**, the browser may copy a short text summary to the system clipboard. This happens only after the user selects the button and only if the browser permits clipboard access.

## Hosting

If a user deploys the file through GitHub Pages or another hosting service, the quiz application itself is still static. Standard hosting-provider logs may exist outside the application's control.
