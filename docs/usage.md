# Usage Guide

## Taking the quiz

1. Open `HappyMe_Happiness_Quiz.html` in a modern browser.
2. Select **Start the quiz**.
3. Read each question and choose the answer that feels closest to you.
4. Use **Next question** to continue or **Back** to revisit a response.
5. After the fifth response, select **See my result**.

## Understanding results

HappyMe calculates a happiness style from the answer categories. The possible styles are:

- **Connection Seeker** — friendship, kindness, and shared time
- **Peace Finder** — calm, rest, and peaceful moments
- **Creative Spark** — expression, learning, and making things
- **Little Explorer** — discovery, novelty, and adventure

The small happiness challenge is a simple invitation to try an activity, not a requirement or diagnosis.

## Replay and sharing

Select **Take the quiz again** to reset all answers. Select **Copy my result** to copy a text summary to the device clipboard where the browser permits clipboard access.

## Browser compatibility

Use an up-to-date version of Chrome, Edge, Firefox, or Safari. The app is not installed, has no server dependency, and works with a local file URL.
